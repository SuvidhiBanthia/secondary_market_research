# Secondary Market Research

This repository focuses on secondary research by scraping recent articles from KPMG and PwC, analyzing them using LLMs, and generating actionable insights.

## Overview

The repository is divided into three main parts:

1.  **Scraping Articles:** Scraping insight articles from KPMG and PwC websites, extracting key information
2.  **Comparative Analysis:** Utilizing AI/ML models to analyze and compare the scraped content, including preprocessing, industry classification, keyword extraction, and clustering.
3.  **Report:** Creating a report summarizing the approach, key industries, top themes, comparative insights, and visualizations.

## Contents

* **Colab Notebook:** Contains the code for scraping (One for PWC, one for KPMG), Analysis.
* **JSON Files:** Raw scraped data
* **Report (Word Doc):** Detailed report
